# CONNEXION Streamlit dashboard

This is the editable Streamlit CONNEXION dashboard. The **WEFH system baseline** and **Policy comparison** pages display exploratory SSP1-2.6 and SSP5-8.5 outputs from the v9.11 Python SDM with IMAGE crop areas. The Crocodile page uses its source workbook. The legacy v9.10 policy data remain in `data.json` but are not used on the current policy page.

## Open the app

Double-click `start_dashboard.cmd`. If the dashboard is already running, it opens that browser page instead of starting a second copy. To start it manually from this folder in PowerShell:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.port 8766
```

Streamlit opens a local browser page. Keep the terminal open while using the app.

## Edit the dashboard

- Edit `content.json` for introductory text, page captions, scenario labels, and partner names.
- The paired baseline feed is `ssp_baseline.json`, generated by `generate_dashboard_image_crop.py` from the IMAGE crop-area model variants and monthly runoff, population, crop-yield, and crop-area inputs. Run that script after updating those inputs, then refresh the browser. `generate_dashboard_ssp_baseline_before_image_crop.py` preserves the previous generator and `ssp_baseline_before_image_crop.json` preserves its output.
- Generate `ssp_policy_ensemble.json` with `generate_ssp_policy_ensemble.py` after refreshing the baseline. It runs the no-policy reference and three defined policy packages under each SSP pathway, with 24 stochastic replicates per combination. The 10th–90th percentile ribbons reflect only the model's existing uniform random draws. They do **not** include climate, crop-area, parameter, policy-effect, or structural uncertainty.
- The baseline charts use sector color and line style (solid SSP1-2.6, dashed SSP5-8.5). Each SSP has its own ribbon. The toggle overlays the previous fixed crop-area runs as dotted lines.
- Absolute baseline and policy trajectories start their y-axes at zero; fractions use 0–100%. Relative-change heatmaps retain signed values around zero.
- The baseline and policy pages include heatmaps showing percent change from 2020 in 2030 and 2049. The policy page also shows percent difference from the no-policy run under the same SSP. Heatmap color is capped at ±100% while the printed number is uncapped; a dash means the reference level is zero. The baseline page lists absolute levels for indicators with a zero 2020 value.
- `evidence.json` and `evidence_audit.md` document the legacy reference notes; they are not displayed as evidence for the new SSP runs.
- Replace image files in `assets/` to change logos. The project logo is `CONNEXION  logo.jpg`.
- Edit `REFERENCE_DISPLAY_ORDER` and `POLICY_COMPARISON_ORDER` near the top of `app.py` to select or reorder plots.
- Edit `sources.json` if source file locations change. Run `python refresh_data.py` after generating new Stella output databases or updating the workbook. Then refresh the browser.

The legacy policy and Crocodile chart data live in `data.json`. The paired SSP baseline lives in `ssp_baseline.json`, so running the legacy `refresh_data.py` does not replace the SSP page. Crop areas now follow IMAGE ISIMIP3b relative change, anchored to MAPSPAM 2020 for maize and soybean. Irrigated sugarcane uses a provisional 42,500 ha 2020 regional proxy; its exact IUWMA area still needs validation. Sugarcane yield, the irrigation-stress envelope, and several other socioeconomic drivers remain at reference settings. These are exploratory pathway comparisons, not validated local SSP forecasts.
